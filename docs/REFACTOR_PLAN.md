# v0.3.0 验收与兼容边界

本版本在既有双 bot、共享人格和记忆系统上增加完整原音理解，并修复发送、提醒、归档、备份和源码发布链路。

## 功能与验证

- 完整原音：保留微信现有文字，将完整语音交给既有附件链路。`listen_audio.py` 复用官方 OpenAI SDK 和 silk-python，把全段音频交给音频模型，再由现有主模型结合观察作答；不新增转写模型或后台服务。
- 发送与提醒：不确定失败不自动重发；提醒创建记录 creating/uncertain 状态，双方部分创建仅补明确未创建的对象。状态锁、损坏预算保护及稳定账号绑定覆盖并发路径。
- 记忆与归档：按来源和归属保留生成记录，未核实送达的内容有明确标注；保留真实重复事件和未核实基线。有效期按实际时刻比较，延期并发不会误使事实失效。
- 备份与发布：复制失败中止并保留旧恢复点；提醒文件纳入备份，全量备份包含原始附件。源码扫描覆盖精确暂存内容；同步默认仅准备改动，显式发布时才提交推送。
- Python 3.12 完整离线回归：79 项通过，包括输入完整性、声音停顿保留、SDK 日志隐私、截断/拒绝结果、提醒不确定状态、真实 ZIP 内容及发布边界。
- 维护版引擎：Weixin 全包 57 项、维护功能重点回归 38 项及 CLI 账号回归通过。约 2 MiB 测试音频从 CDN 解密到附件落盘逐字节一致。
- 集成：公开 WAV/SILK 音频的真实音频 API 请求通过；维护部署已完成真实微信原音附件、听音调用与返回观察的链路验证。私人原音、对话和部署证据不包含在本仓库中。

## 升级与回退

安装 `requirements.txt`，在现有语音 Python 3.12 环境中复用依赖。原音接收需要 `deploy/cc-connect-voice-attachment.patch` 对应的维护版 cc-connect；仅更新 Python 脚本不能让旧接收层保留原音。

更新前备份工具、提示词、引擎和会话，空闲时受控切换；回退代码时保留最新会话历史。私人配置、凭据、记忆、附件、素材和二进制均保持本地。

## 已知边界

- 语气和情绪是基于声音的推测，不应自动升级为永久事实；项目提示词中的信息流向不是操作系统级隔离。
- 归档待审核范围与消息是否送达分别判断，不因捕获任务成功就宣称历史完整。明确删除的历史不恢复。
- ZIP 内容检查不等于全机恢复演练；热备份数据库和会话一致性仍需恢复验证。
- 原保留 Go CLI 全套测试有既存 Windows doctor 测试编译限制；本版本生产构建、目标包和维护回归通过，不宣称全套 Go 测试通过。
- 公共仓库未完整包含此前全部定制 Go 补丁；官方 npm 安装不能自动复现全部共享记忆行为，详见 [源码核对](source-reconciliation.md)。
